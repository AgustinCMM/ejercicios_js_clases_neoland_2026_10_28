Consigna

40. El Jefe Final: Crea una clase BandaMusical. El constructor debe recibir un array vacío. Debe tener un método agregarMusico(musico) que inserte un objeto en el array interno de la clase. Crea clases Guitarrista, Baterista y Cantante, cada uno con un método tocar() distinto. Agrega uno de cada uno a una instancia de BandaMusical. Finalmente, la banda debe tener un método darConcierto() que recorra su propio array interno de músicos y ejecute el método tocar() de todos a la vez.
